# MIU Cover Page Generator

A modern, user-friendly web application designed to help students of **all departments at Manarat International University (MIU)** create professional Assignment and Lab Report cover pages with ease.

Generate well-structured, university-style cover pages, preview them instantly, and download them as PDF documents.

---

## Overview

**MIU Cover Page Generator** simplifies the process of preparing academic cover pages. Students can enter their academic information, select a document type, preview the layout in real time, and download a print-ready PDF.

The application is designed with simplicity, accessibility, and consistency in mind, making it suitable for students across all academic departments.

## Features

- **Assignment Cover Page** – Generate professional assignment cover pages.
- **Lab Report Cover Page** – Create properly formatted lab report cover pages.
- **All Departments Supported** – Designed for students across MIU departments.
- **Live Preview** – View changes instantly before downloading.
- **PDF Export** – Download cover pages as PDF documents.
- **University Branding** – Includes Manarat International University logo and watermark.
- **Responsive Interface** – Designed for desktop and mobile devices.
- **Progressive Web App (PWA)** – Install the application on supported devices.
- **Simple User Experience** – Easy-to-use interface with a straightforward workflow.

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/miu-cover-page-generator.git
   ```

2. Open the project folder:

   ```bash
   cd miu-cover-page-generator
   ```

3. Open `index.html` in your browser.

For full PWA functionality, run the project through a local HTTP server or deploy it using HTTPS.

## Installation as an App

MIU Cover Page Generator supports installation as a Progressive Web App.

1. Open the deployed website in a supported browser.
2. Select **Install App** or **Add to Home Screen**.
3. Confirm the installation.
4. Launch the application from your device.
